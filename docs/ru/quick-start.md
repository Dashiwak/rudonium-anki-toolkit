# Быстрый старт

При первом экспорте вы отправите в Anki одну карточку из сохранённой заметки Markdown.

Уже есть карточки другого плагина, по одной на файл? Для чистой установки откройте команду **Quick Start** и выберите **Migrate existing card files**. [Руководство по переносу](migrate-card-files.md) объясняет форматы, проверку связей и создание полной копии хранилища.

Если в хранилище отсутствуют правила формата и блоки с парными маркерами, мастер настройки откроется автоматически. Его можно повторно открыть через **Подключение к Anki → Первый запуск** или командой **Быстрый старт**. Для открытия мастера подключение к Anki не требуется.

## Установить или обновить плагин

Скачайте установочный архив `Rudonium-<версия>.zip` из последнего опубликованного выпуска. Закройте Obsidian и распакуйте архив в `.obsidian/plugins/` своего хранилища. Откройте хранилище и включите плагин в **Настройки → Сторонние плагины**. [Проект на GitFlic](https://gitflic.ru/project/dashiwak/rudonium-anki-toolkit)

Если в настройках Rudonium показан номер, отличающийся от версии установленного выпуска, закройте Obsidian и замените `main.js`, `manifest.json` и стили из одного выпуска в папке `.obsidian/plugins/rudonium-anki-toolkit/`. Сохраните файлы настроек, кеша и журналов. Снова откройте хранилище. Чтобы сменить язык, откройте настройки плагина. Раскройте **Interface and plugin information** и выберите язык в строке **Interface Language**.

## Подключение

1. На том же компьютере, где установлен Obsidian, откройте настольную Anki и выберите **Инструменты → Дополнения → Загрузить дополнения**. Введите код `2055492159`, подтвердите установку и перезапустите Anki. [AnkiConnect на AnkiWeb](https://ankiweb.net/shared/info/2055492159)
2. Откройте **Инструменты → Дополнения**, выберите **AnkiConnect** и нажмите **Настройки** (Config). Найдите `webCorsOriginList` и добавьте в список `"app://obsidian.md"`. Сохраните имеющиеся адреса и остальные настройки. Если в списке уже есть стандартный адрес localhost, результат будет таким:

   ```json
   ["http://localhost", "app://obsidian.md"]
   ```

3. Сохраните конфигурацию и перезапустите Anki. Откройте профиль, в котором будете повторять карточки, и оставьте коллекцию открытой на время работы с Rudonium. Плагин использует локальный адрес `127.0.0.1`, порт `8765` и стандартную конфигурацию AnkiConnect со значением `null` у `apiKey`.
4. В **Быстром старте** нажмите **Проверить соединение**. Сверьте имя профиля. Для первого примера ниже выберите обычную колоду, тип записи с двумя полями, например **Basic** («Простая»), и формат **RemNote**. При ошибке проверьте, включено ли дополнение, указан ли порт 8765 и точно ли введён адрес Obsidian.
5. Сравните пример Markdown с лицевой и обратной сторонами в мастере. В **Дополнительных настройках** можно **посмотреть шаблон Anki**. Нажмите **Сохранить настройку**.

На новой установке двусторонняя синхронизация выключена, поле **Тег по умолчанию** пустое. Впишите тег, если хотите добавлять его к экспортируемым записям. **Интервал автосканирования (минуты)** задаёт частоту проверки заметок для экспорта. Оставьте 0, чтобы запускать проверку вручную.

В настройках плагина выберите колоду по умолчанию из активного профиля Anki. Вложенная колода сохраняет полное имя, например `Knowledge::Deutsch`. Если колоды недоступны, откройте Anki и обновите список. Для настройки тегов раскройте стрелкой ветку нужной папки или найдите папку по её пути. Кнопка для следующих папок появляется, только когда в открытых ветках или в результатах поиска есть ещё строки.

## Экспорт одной карточки

В заметке Markdown внутри выбранной папки введите строку и сохраните заметку.

```markdown
Какой город является столицей Австрии? :: Вена
```

1. Поставьте курсор в текст примера и выберите в палитре команд **Preview Current Card** («Предпросмотр текущей карточки»). Проверьте вопрос, ответ и колоду.
2. Нажмите **Sync this card** («Синхронизировать эту карточку»). Проверьте предложенное создание записи и подтвердите экспорт. Rudonium запишет рядом с карточкой ID записи Anki. При последующих правках сохраняйте этот ID рядом с карточкой.
3. Оставив курсор в карточке, выполните **Open Current Card in Anki** («Открыть текущую карточку в Anki»). Тем же способом можно проверить и применить правку одной карточки в заметке, содержащей несколько записей. Если после открытия предпросмотра вы отредактировали Markdown, сохраните его и откройте предпросмотр заново.

В двустороннем режиме общий предпросмотр сверяет записи, у которых уже есть ID. Чтобы добавить новую карточку, поставьте курсор в её текст в редакторе и в этом окне нажмите **Новая карточка под курсором…**. Проверьте образец, нажмите **Синхронизировать эту карточку** и подтвердите создание. Остальные черновики заметки сохранятся для дальнейшей работы.

Раскройте **Настройки синхронизации**, включите **Двусторонняя синхронизация** и нажмите **Синхронизировать**. Кнопка на ленте запускает ту же проверку. Если предпросмотр выключен, проверенные изменения применяются сразу. Если одно связанное поле изменили в обеих программах, по умолчанию используется более поздняя версия, когда время позволяет определить порядок. Чтобы всегда выбирать такие значения вручную, выключите **Применять более позднюю правку**. В этом же разделе доступен предпросмотр. У каждой доступной стрелки указаны источник и получатель. Выберите направление переноса и нажмите **Применить синхронизацию**.

## Синхронизировать один файл

В палитре команд выберите **Синхронизировать текущий файл с Anki**. В одностороннем режиме плагин обрабатывает распознанные карточки открытой заметки, включая новые. Если после подтверждённой синхронизации текст связанного поля изменили и там, и там, при одностороннем экспорте используется текст из Obsidian. Изменение, сделанное только в Anki, сохраняется в Anki. Неоднозначные изменения и действия с риском потери данных можно проверить в предпросмотре экспорта. В двустороннем режиме применяются проверенные изменения связанных записей, а при ручном запуске показывается результат. Включите **Предпросмотр при каждом запуске**, если хотите сначала просматривать каждый план. Если время двух правок совпадает или его недостаточно для сравнения, конфликт остаётся в предпросмотре. Подтверждение удаления также доступно в предпросмотре. Чтобы их разобрать, нажмите **Открыть предпросмотр** в настройках синхронизации. Тот же переключатель доступен в самом окне. Для новой карточки используйте действие под курсором. В заголовке области указан путь к файлу. При переключении вкладки выбранный файл сохраняется.

## Добавление другого формата

Для экспорта строки с четырьмя полями через двоеточие выберите тип записи и откройте **Мастер регулярных выражений**. Проверьте пример и соответствие значений полям Anki, нажмите **Использовать формат** и сохраните настройку. [Пример и поддерживаемое направление](card-formats.md#создать-правило-по-разделителю)

В настройках откройте **Правила типов записей** и нажмите **Добавить правило**. Выберите тип записи активного профиля Anki и готовый формат или введите своё регулярное выражение. Здесь же можно выбрать поля Anki для ссылки на файл и для контекста. Включите соответствующую основную настройку **Добавлять ссылку на заметку** или **Добавлять контекст**, чтобы эти данные попадали в карточку. Сохраните правило. Если формат для типа уже задан, откройте существующее правило для редактирования. [Примеры форматов Markdown](card-formats.md)

Чтобы сделать **отдельную страницу одной карточкой**, выберите формат страницы для её типа записи Anki. Поставьте `#anki-page` в обычном тексте страницы либо добавьте `anki-page` в свойство YAML `tags`. Напишите вопрос в первом заголовке первого уровня, а ответ — под ним. При первой привязке Rudonium по умолчанию запишет ID в свойство YAML `anki-page-ID`. В редакторе команда **Добавить поле страницы Anki…** предлагает выбрать поле и ввести значение. Если на старой странице стоит `rudonium-id`, переименуйте этот ключ в `anki-page-ID`, сохранив исходные цифры. [Примеры, дополнительные поля и расположения ID](card-formats.md#целая-страница)

```markdown
# Какой город является столицей Австрии? #anki-page

Вена.
```

## Если в Markdown пропал ID

Если вы уже повторяли карточку в Anki, а её ID исчез из текста Obsidian, откройте аудит колоды и нажмите **Проверить карточки без ID**. Так вы проверите выбранную колоду в активном профиле папок. Чтобы включить карточки, которым в этом профиле назначены другие колоды, запустите **Проверить карточки без ID** из палитры команд. Поиск выполняется один раз по вашему запросу, независимо от обычной синхронизации и первоначальной сверки колоды.

В разделе **Можно восстановить** у каждой карточки вопрос, ответ, тип и колода совпали с одной записью Anki, а её ID свободен в хранилище. Спорные случаи появятся в разделе **Нужна ручная проверка**. В число **Без точного совпадения** входят как новые черновики, так и ранее экспортированные карточки, у которых изменились поля, тип или колода. Отметьте знакомые записи и нажмите **Восстановить выбранные ID**. Rudonium создаст ZIP всего хранилища, ещё раз сверит связи и запишет ID в Markdown. Записи Anki сохранят свою историю повторений.

## Если в Markdown есть ID, но запись в Anki пропала

Проверьте, открыт ли нужный профиль Anki. Запустите **Сверить колоду по умолчанию с Anki → Проверить без записи** и откройте нужную запись. В уведомлении о пропавшем ID нажмите **Исправить запись**. Плагин проверит колоду без записи и откроет исправление для указанного ID. Кнопка **Пропустить** переходит к следующей ошибочной записи. Весь список остаётся в отчёте аудита. При переходе к строке в Obsidian отчёт или окно исправления остаётся справа от редактора. В окне исправления переходите к предыдущей или следующей записи. Если нашлась похожая запись, сравните поля перед заменой ID. [Поддержка на GitFlic](https://gitflic.ru/project/dashiwak/rudonium-anki-toolkit/issue)

[Приостановка, удаление и общие поля](card-controls.md)

## Если экспорт ничего не отправил

При формате RemNote пример ниже представляет одну карточку. В модели с полем `BackLang` значение `de_DE` указывает язык ответа.

```markdown
**Карточки**
- Как называется ресторан у подножия Ракса?+++ :: Wirtshaus zum Raxkönig :: B=de_DE
```

Для проверки новой строки поставьте в неё курсор, откройте **Предпросмотр текущей карточки** и выберите **Синхронизировать эту карточку**. После подтверждения создания проверьте появление ID в Markdown. Изменение размера заметки служит поводом перечитать файл. Если вы добавили пробел вокруг разделителя и значения полей остались прежними, повторная запись в Anki не требуется.

## Если ID повторился или экспорт прервался

Если у двух карточек Markdown один ID, выберите команду **Проверить дубликаты ID Anki**. Сравните указанные строки, оставьте ID у исходной карточки и сохраните правки. Для перехода к этой карточке из другой заметки можно поставить ссылку. Нажмите **Проверить повторно** и синхронизируйте изменённый файл.

Если экспорт прервался после создания записи в Anki, выберите команду **Проверить незавершённое создание записей Anki**. Сверьте профиль, имя файла и найденную запись в Anki. Команда **Проверить и восстановить** повторно проверит запись и восстановит связь с исходной карточкой.

## Резервная копия и восстановление

В настройках резервных копий нажмите **Создать резервную копию** или включите автоматическое копирование перед экспортом и задайте интервал в днях. По умолчанию папка `Obsidian Anki Backups` создаётся рядом с хранилищем. В копию можно включить активный профиль Anki, если настольная среда поддерживает оперативное копирование SQLite. Чтобы восстановить хранилище, выберите его ZIP и нажмите **Восстановить в новую папку**. Откройте её в Obsidian и проверьте заметки перед переносом в рабочее хранилище.

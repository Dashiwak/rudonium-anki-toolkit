# Перенос карточек из другого плагина

Мастер подходит, если один Markdown-файл представляет одну запись Anki с вопросом и ответом. Он преобразует выбранные файлы на месте. Пути и ссылки на них из других заметок сохраняются. Предлагаемые изменения можно проверить перед созданием копии и переносом.

## Как открыть мастер

1. Сохраните открытые правки в Obsidian и отключите плагин, который раньше синхронизировал эти файлы. Оставьте его настройки и данные в хранилище для резервной копии. После переноса оставьте Yanki отключённым для перенесённых папок. Если его собственный ID исчезнет из файла, следующая синхронизация Yanki может удалить запись в Anki и создать её заново с новой историей повторений. [Пояснение автора Yanki](https://github.com/kitschpatrol/yanki-obsidian#can-i-delete-the-noteid)
2. Откройте прежний профиль Anki и проверьте, что AnkiConnect работает. Для новой установки откройте из палитры команд **Quick Start** выберите **Migrate existing card files**, проверьте соединение и нажмите **Continue to migration**. На настроенном плагине выполните команду **Перенести карточки из файлов** или откройте **Перенос карточек из файлов → Открыть мастер** в настройках Rudonium. При копировании прежних настроек можно также выбрать проверку файлов после копирования.
3. Для проверки всего хранилища оставьте автоматическое распознавание и пустое поле папки. Чтобы ограничить перенос, укажите исходный формат или папку. Мастер проверяет повторяющиеся ID по всему хранилищу. Для автоматического поиска ID Yanki сохраните отключённый плагин в хранилище. Чтобы включить файлы Yanki без ID, явно выберите **Yanki** и папку его карточек. Если такой папкой был корень хранилища, введите `/`, чтобы включить файлы без ID. При автоматическом поиске пустое поле папки означает поиск маркированных карточек. Подсказки папок основаны на уже проиндексированных свойствах `noteId`. Горизонтальный разделитель часто встречается в обычном тексте и сам по себе не позволяет распознать карточку.
4. Выберите тип записи Anki по умолчанию для новых страниц. Если в разделе **Правила типов записей** уже назначен формат `@page`, укажите этот тип. Иначе мастер может добавить распознавание страниц к типу с настроенным регулярным выражением. Нажмите **Проверить файлы**. Мастер проверит уже указанные ID. Файлы, для которых можно поискать потерянные ID, появятся в разделе **Ожидает проверки**.
5. Чтобы включить карточки без ID, нажмите **Проверить карточки без ID**. Это разовый поиск в выбранной области переноса. Проверьте каждую предложенную связь. В разделе **Готово к переносу** отметьте нужные файлы. Если вы выбрали файл, который раньше не экспортировали, подтвердите, что обычный экспорт сможет создать для него запись Anki. В разделе **Проверить вручную** указана причина, по которой мастер отложил файл. В разделе **Уже преобразовано** перечислены существующие страницы Rudonium.
6. Выберите папку для копии вне хранилища и нажмите **Создать копию и преобразовать**. Сохраните показанный путь к ZIP. Откройте преобразованный файл и проверьте в предпросмотре следующего экспорта запись Anki и целевую колоду.

## Как восстановить потерянный ID

После разовой проверки выберите фильтр **Точное совпадение в Anki**. Разверните найденную запись, прочитайте вопрос и ответ, проверьте тип, колоду и числовой ID. Если это прежняя запись, отметьте **Связать с этой записью** под нужным файлом. Каждая отметка действует для одной пары «файл — ID». Команда **Выбрать все готовые файлы** сохраняет индивидуальный выбор связей. При повторном сканировании мастер запросит подтверждение заново.

Мастер предлагает связь при точном совпадении обоих полей, типа записи и колоды с одной подходящей записью Anki. Если в файле не указан прежний тип или колода, проверьте выбранный тип и целевую колоду для этого файла до поиска. Он проверяет, свободен ли ID во всём хранилище, включая файлы за пределами выбранной папки. После проверки ZIP мастер повторно проверяет связь и записывает ID в Markdown. Последующие экспорты смогут обновлять ту же запись Anki с её историей повторений. Если ответы отличаются, совпадений несколько или ID занят другим файлом, нужна ручная проверка.

Если карточки уже в формате Rudonium, запустите **Проверить карточки без ID** из аудита колоды или палитры команд. У страницы-карточки сохранятся первый заголовок первого уровня и тег страницы, а восстановленный ID будет записан в место, выбранное в разделе **Маркеры ID Anki**. При переходе с другого плагина запускайте проверку в мастере переноса, чтобы он прочитал разметку в её исходном формате. [Как вернуть ID в Rudonium](quick-start.md#если-в-markdown-пропал-id)

## Какие файлы распознаются

| Источник | Как выглядит файл одной карточки | Когда нужна ручная проверка |
| --- | --- | --- |
| Yanki (Basic) | Вопрос занимает одну строку. За ним идут пустая строка, отдельная строка `---` и непустой ответ. В свойстве YAML `noteId` Yanki сохраняет числовой ID записи Anki. | У обратных карточек, пропусков и карточек с вводом ответа другой режим повторения. |
| Flashcards v1/v2 от reuseman | Весь файл занимает одна простая карточка. Поддерживаются вопрос или заголовок с `#card`, выноска `[!CARD]` и блок кода `flashcard` с полями `front` и `back`. При явном выборе источника можно также перенести одиночную строку `вопрос :: ответ` без маркера и поддерживаемые варианты YAML-свойства `test`. | Несколько карточек, напоминания, обратные карточки, пропуски, пользовательские маркеры и неоднозначные ID. В v1 связь может храниться в числовом якоре. В v2 якорю `^q-…` должна соответствовать запись с числовым `nid` в свойстве `flashcards`. |
| Obsidian_to_Anki (Export to Anki) | Один явный блок простой записи между `START` и `END` с вопросом и ответом. | Другие блоки и содержимое вне карточки, пользовательские соответствия полей. |
| Deck To Anki | В YAML указано `deckType: card` с разделителем вопроса и ответа или `deckType: title`, где вопросом служит имя файла. У экспортированной записи ID Anki хранится в `deckID`. | Режимы заголовков, списков и файлов-индексов могут описывать группу карточек. Архивные записи, собственные названия колод и несовместимые шаблоны требуют проверки. |
| Anki Forge от keptan | Одна простая карточка `Вопрос::Ответ` или `Вопрос #card` с ответом ниже. Конечный якорь `^af-…` сохраняется. Свойство YAML `anki-deck` указывает исходную колоду. Для записи с общей разметкой без меток Forge выберите источник вручную. | При наличии якоря Forge или прежних данных плагина подтвердите исходную запись Anki. Собственные разделители, несколько карточек, пропуски и обратные карточки требуют проверки. |
| Anki Bridge от Aaron Ade | Одна карточка Basic или многострочная Dump со служебными метками `%%oab:…:v1%%`. При обнаружении исходного реестра путь колоды начинается с `Obsidian Flashcards`, затем идут имя хранилища, путь папки и имя файла без расширения. | При обнаружении прежнего реестра требуется подтверждённая связь. Несколько карточек, текст вне карточки, обратные карточки, списки, пропуски и скрытые фрагменты изображений требуют проверки. |
| Anki AST Sync | Одна карточка Basic, в YAML файла `AnkiSync: on` или `true`. По умолчанию это заголовок четвёртого уровня, отдельная строка `:::` и ответ. Между заголовком и разделителем может быть одна строка вопроса. В этом случае исходный заголовок сохраняется в свойстве YAML `rudonium-source-heading`. | Сохранённый UUID относится к карточке источника. Для него нужно подтвердить запись Anki. Несколько секций, собственные типы, встроенные заметки, обратные карточки, ввод ответа и пропуски требуют проверки. |
| Anki Exporter от Erik Mielke | Одна строка `Вопрос :: Ответ` с одним пробелом по обе стороны `::`. Числовая метка `<!-- anki-note-id:123456789 -->` непосредственно над ней указывает на экспортированную запись. Без метки выберите источник вручную. | Несколько карточек, текст за их пределами или повреждённый ID требуют проверки. |
| Spaced Repetition | Мастер распознаёт комментарий локального расписания, начинающийся с `<!--SR:!`. | Запись попадает в ручную проверку. Локальное расписание не содержит ID записи Anki и не переносит историю повторений в Anki. |

Если перенос остановился после создания ZIP, сохраните архив и запустите проверку заново. Мастер распознаёт страницы, которые уже помечены `#anki-page`.

**Better Flashcards.** Это форк Flashcards. Для файла с общей разметкой выберите в мастере **Flashcards** и проверьте результат предпросмотра. Перед записью мастер проверяет, отключён ли Better Flashcards. Специфичные для форка форматы отдельно не проверялись. [Проект Better Flashcards](https://github.com/mihirpatel1112/better-flashcards#attribution)

## Как выглядит результат

Для формата `@page` мастер записывает вопрос в первый заголовок первого уровня. Настройка **Расположение ID страницы-карточки** определяет, куда будет записан проверенный ID. По умолчанию мастер записывает его в свойство YAML `anki-page-ID`. Если у страницы Rudonium остался прежний ключ `rudonium-id`, проверьте номер записи Anki и переименуйте свойство в `anki-page-ID` перед переносом. Для новых связей можно выбрать **Под заголовком** или **После ответа**. Во втором варианте служебный HTML-комментарий помещается в конец публичного ответа. Если в исходной строке ID есть авторская пометка, мастер сохраняет строку целиком под заголовком. Ниже приведён пример связанной страницы при выборе **Под заголовком**.

```markdown
# Какой город является столицей Австрии? #anki-page
<!--ID: 1700000000001-->
<!--rudonium-page-route: ["Yanki - Basic","Geography"]-->

Вена.
```

В скрытой строке под помеченным заголовком записаны подтверждённые тип записи и колода. Мастер также может сохранить теги связанной записи Anki в скрытом комментарии. Оставьте эти комментарии в заметке. Сохраняются сторонние свойства YAML и распознанные якоря блоков Flashcards. Для стандартного типа Deck To Anki могут использоваться поля `ob-deck-front` и `ob-deck-back`. У новой карточки ID появится при обычном экспорте после создания записи в Anki. Можно проверить работу мастера до отправки изменений в Anki. [Формат карточки-страницы](card-formats.md)

## Как вернуть исходные файлы

Сохраните ZIP до проверки карточек. В архив входят файлы хранилища, настройки Obsidian, данные установленных плагинов и вложения. Коллекция Anki хранится отдельно в самой Anki. Чтобы открыть исходное хранилище, перейдите в **Резервные копии**, укажите путь к ZIP и выберите **Восстановить в новую папку**. Откройте эту папку как отдельное хранилище и проверьте заметки до включения синхронизации.

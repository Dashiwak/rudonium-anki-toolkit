# Rudonium Anki Toolkit 0.10.5

## Русский

Ссылка на помощь и переключатель двусторонней синхронизации находятся в начале настроек. Язык интерфейса выбирается внизу. Остальные параметры остались в разделе синхронизации.

Когда «Предпросмотр при каждом запуске» выключен, плагин применяет проверенные изменения в фоне. Конфликты и удаления, требующие решения, остаются для ручной проверки. Откройте предпросмотр из настроек, чтобы выбрать версию поля или подтвердить удаление. При ошибке связи или записи плагин сообщает причину. Исправлена обработка некорректных ответов Anki и сохранённых данных.

В Windows команда `Prepare-GitFlic.cmd` складывает результаты в отдельный каталог для каждой сборки. [Инструкция по сборке](../../PUBLISHING.md)

## English

The help link and bidirectional sync switch are at the top of settings. Interface language is at the bottom. Advanced sync options remain in the sync section.

With **Preview every sync** off, verified changes are applied in the background. Conflicts and deletions that require a decision remain pending. Open the preview in settings to choose a field value or confirm a deletion. Connection and write errors still show their cause. The plugin also checks malformed Anki responses and saved data before using them.

On Windows, `Prepare-GitFlic.cmd` writes each build to its own output directory. [Build instructions](../../PUBLISHING.md)

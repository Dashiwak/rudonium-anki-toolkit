# Rudonium Anki Toolkit 0.13.0

## English

- When Obsidian_to_Anki is enabled, open the switch dialog from the ribbon and use its link to find the plugin in Community plugins. Disable it there. Rudonium detects the change and lets you import its settings without restarting.
- Keep your previous block markers, regular expressions and per-note-type file and context assignments. Two-way sync, scheduled backups and change logging start switched off when moving from Obsidian_to_Anki.
- Closing Quick Start before saving lets you resume setup next time. Select “Don’t show Quick Start automatically” to dismiss it. The example uses the Vostok 1 card from the README.
- Quick Start no longer reads the vault's Markdown files to decide whether to open. “Skip all” dismisses the remaining missing-ID notices for the current scan. The audit remains available.
- Backups can include a separate Anki deck package with scheduling data. Choose the deck in the backup settings.
- Replaced Showdown with Marked and updated the runtime glob matcher. The formatter is checked against the original Anki HTML examples.
- Tagged GitHub builds verify the release files and report their SHA-256 digests. Use the three files in the verified candidate's install folder when publishing.

## Русский

- Если включён Obsidian_to_Anki, на боковой панели появляется кнопка перехода. Откройте окно перехода, перейдите по ссылке к старому плагину и отключите его. Rudonium обнаружит изменение и предложит перенести настройки без перезапуска.
- При переходе сохраняются прежние маркеры блоков, регулярные выражения и назначения полей файла и контекста для каждого типа записи. Двусторонняя синхронизация, резервное копирование по расписанию и журнал изменений изначально выключены.
- Если закрыть «Быстрый старт» до сохранения, при следующем запуске настройку можно продолжить. Галочка «Не показывать быстрый старт автоматически» отключает повторный показ. В примере используется карточка о «Востоке-1» из README.
- Для решения о показе мастера Rudonium больше не читает Markdown-файлы хранилища. Кнопка «Пропустить все» скрывает оставшиеся уведомления о ненайденных ID для текущей проверки. Результаты доступны для сверки.
- В резервную копию можно включить отдельный пакет колоды Anki с расписанием повторений. Колоду выбирают в настройках резервного копирования.
- Для преобразования Markdown вместо Showdown используется Marked. Обновлена библиотека, которая сопоставляет пути с масками. Форматирование сверяется с примерами HTML из Obsidian_to_Anki.
- Сборка тега на GitHub проверяет файлы выпуска и выводит их SHA-256. Для публикации используйте три файла из папки install проверенной сборки.

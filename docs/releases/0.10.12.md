# Rudonium Anki Toolkit 0.10.12

## Русский

- Двусторонняя синхронизация по умолчанию выключена. При её включении изменения связанного поля переносятся в нужную сторону. Если это поле изменили и в Obsidian, и в Anki, плагин выбирает более позднюю версию, когда по времени можно установить порядок. Сравниваются время файла Markdown и записи Anki с точностью до секунды. Если времена совпали, изменилось несколько конфликтующих карточек или нельзя отнести изменение к одному полю, запись откладывается для предпросмотра. Для первого сравнения без истории в файле должна быть одна связанная карточка.
- Раскройте настройки синхронизации, чтобы включить предпросмотр при каждом запуске. Переключатель **Применять более позднюю правку** включён по умолчанию. Если его выключить, конфликты остаются для ручного выбора, а остальные проверенные записи синхронизируются. Изменения, требующие выбора направления или подтверждения удаления, можно разобрать в предпросмотре вручную.
- Предпросмотр показывает значения поля в Obsidian и Anki и доступные направления переноса. Выберите стрелку **Obsidian → Anki**, чтобы отправить значение из заметки, или **Anki → Obsidian**, чтобы принять значение из Anki. Нажмите **Применить синхронизацию**, чтобы выполнить выбранные изменения.
- В полях карточек распознаётся Markdown `**текст**` и соответствующее выделение `<b>` или `<strong>` в Anki. Теги с атрибутами, пересекающаяся разметка или неоднозначный порядок полей требуют ручной проверки.
- В разделе «О плагине» и документации вопросы и сообщения об ошибках направляются на GitFlic. [Поддержка](https://gitflic.ru/project/dashiwak/rudonium-anki-toolkit/issue)

После успешной локальной сборки установочные файлы находятся в `Rudonium-Builds/0.10.12/install/`. [Порядок сборки](../../PUBLISHING.md)

## English

- Bidirectional sync is off by default. When enabled, it transfers edits to linked fields. If both Obsidian and Anki changed the same field, sync selects the later version when the timestamps establish an order. Sync compares file and note times at one-second resolution. Matching timestamps, several conflicting cards or unknown field-level ordering leave the note available for review. Without a previous checkpoint, only a file with one linked card is eligible for an automatic direction.
- Expand sync settings to enable preview for every sync. **Apply the newer edit** is on by default. Turn it off to review conflicts manually while other verified notes continue to sync. Open the preview to resolve pending directions and confirm deletions.
- The preview compares Obsidian and Anki field values. Select **Obsidian → Anki** to send the Markdown value or **Anki → Obsidian** to accept the Anki value. Apply the selection to perform the proposed changes.
- Markdown `**text**` and matching `<b>` or `<strong>` in Anki are supported in card fields. Tags with attributes, overlapping markup or ambiguous field order require manual review.
- About and the documentation direct questions and bug reports to GitFlic. [Support](https://gitflic.ru/project/dashiwak/rudonium-anki-toolkit/issue)

The local build writes the installation files to `Rudonium-Builds/0.10.12/install/`. [Build instructions](../../PUBLISHING.md)

# Rudonium Anki Toolkit 0.10.7

## Русский

При запуске `Apply-Update.cmd` в синхронизируемой папке Windows проверка могла остановиться с сообщением `File changed while opening`, даже когда содержимое файла совпадало с исходниками. Такой случай наблюдался с `.dockerignore`. Исправлена проверка чтения файлов. Перед применением обновления команда по-прежнему сверяет контрольные суммы проектных файлов. Сборщик также проверяет содержимое при чтении лицензий зависимостей и при упаковке установочных файлов.

Обновление накопительное. Если вы уже применяли комплект 0.10.5.1, распакуйте 0.10.7 в отдельную папку внутри `Rudonium-Incoming` и запустите из неё `Apply-Update.cmd`. В качестве базы подходит сохранённый полный архив 0.10.4. [Порядок сборки](../../PUBLISHING.md)

## English

When run in a synced Windows folder, `Apply-Update.cmd` could stop with `File changed while opening` even though the file contents matched the expected source. This was reported for `.dockerignore`. The file read check has been corrected. The updater still verifies the project file checksums before applying changes. The same content checks cover dependency notices and the files packaged in the installer.

If you applied the 0.10.5.1 update, extract the cumulative 0.10.7 package into its own folder inside `Rudonium-Incoming` and run `Apply-Update.cmd` there. Your full 0.10.4 source archive can serve as the base. [Build instructions](../../PUBLISHING.md)

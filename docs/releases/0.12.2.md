# Rudonium Anki Toolkit 0.12.2

## Русский

- В README на русском и английском добавлен пример первой карточки RemNote с готовым регулярным выражением и иллюстрацией до и после получения ID.
- В «Быстром старте» код дополнения, адрес Obsidian и конфигурацию AnkiConnect можно скопировать значками рядом с образцами. Подписи в настройках различают настройку синхронизации и перенос карточек.
- При проверке хранилища обычные Markdown-файлы без карточек пропускаются без отдельного уведомления.
- Исправлена обработка правок одного поля с обеих сторон, когда изменились и соседние поля. Если порядок правок удаётся установить, применяется более поздняя. Если порядок неоднозначен, направление можно выбрать в предпросмотре.
- При автоматической двусторонней синхронизации параметр «Пропускать ошибки отдельных карточек» позволяет продолжить работу с исправными записями. Если его выключить, ошибка карточки приостанавливает операцию до внесения изменений.

## English

- Both READMEs show how to create a first RemNote card with the built-in regular expression and an illustrated before-and-after example of the Anki note ID.
- Quick Start has compact copy buttons beside the AnkiConnect add-on code, Obsidian origin, and sample configuration. Settings buttons distinguish sync setup from card file migration.
- Vault scans silently skip ordinary Markdown files that contain no cards.
- Fixed conflict handling when both apps edit the same field and other fields have also changed. When the edit order can be established, the later edit wins. If the order is unclear, choose the direction in the preview.
- During automatic bidirectional sync, **Skip recoverable card errors** lets other notes sync when one card has a recoverable error. With the setting off, such an error pauses the sync before any changes are applied.

# Rudonium Anki Toolkit 0.13.3

## English

- In Quick Start, **Note types** groups the configured rules and the button for adding a type. In the rule editor, the format, expression and file and context fields are visible together. Optional rule tools open on demand. A valid custom expression can be saved without entering sample Markdown.
- The export notice reports skipped notes separately from files that need review. **Run audit** uses the default deck selected in Rudonium settings. You can switch decks in the audit.
- New installations enable **Skip individual card errors** and **Apply the newer edit** by default. Existing preferences are preserved. The README and Quick Start guide explain how to start a sync with the Anki button on the left ribbon.

## Русский

- В «Быстром старте» раздел **Типы записей** объединяет настроенные правила и кнопку добавления типа. В редакторе рядом находятся формат, своё выражение, поле ссылки на файл и поле контекста. Мастер и проверки можно раскрыть отдельно. Для сохранения корректного выражения пример Markdown вводить необязательно.
- Уведомление об экспорте показывает пропущенные записи отдельно от файлов, требующих проверки. **Провести аудит** запускает проверку колоды из настроек Rudonium. Выбрать другую колоду можно в окне аудита.
- При первом запуске включены **Пропускать ошибки отдельных карточек** и **Применять более позднюю правку**. При обновлении сохраняется прежний выбор пользователя. В README и руководстве по быстрому старту показано, как запустить синхронизацию кнопкой Anki на левой ленте.

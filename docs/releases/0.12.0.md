# Rudonium Anki Toolkit 0.12.0

## Русский

- Исправлены циклические импорты сканера и типы операций с ZIP и резервными копиями. ESLint и Rollup останавливают проверку релиза при предупреждении. При публикации GitHub Actions сравнивает файлы релиза с проверенной сборкой перед подтверждением их происхождения.

- Результат синхронизации указывает число записей и приложение, в котором они изменились. Например, «Проверено 19 записей» и «Изменена 1 запись в Anki».
- Синхронизация восстанавливает пропущенные пробелы возле однозначно распознанного разделителя `::` без отдельного уведомления. При двусторонней синхронизации правка поля в Anki может вернуться в Obsidian в том же запуске.
- В «Быстром старте» можно открыть страницу AnkiConnect и скопировать пример конфигурации. Для существующей настройки достаточно добавить Obsidian в список разрешённых приложений, сохранив остальные значения.

## English

- Removed circular imports from the scanner and tightened the types used by ZIP and backup operations. Warnings now fail the ESLint and Rollup checks. On publication, GitHub Actions compares the release assets with the verified build before attesting them.

- Sync results now give the number of notes and the app where they changed, for example “Checked 19 notes” and “Updated 1 note in Anki”.
- Sync restores missing spaces around an unambiguous `::` separator without a separate notice. In bidirectional mode, a field edited in Anki can return to Obsidian during the same run.
- Quick Start links to AnkiConnect and includes a copyable configuration example. For an existing configuration, add the Obsidian origin and keep your other settings.

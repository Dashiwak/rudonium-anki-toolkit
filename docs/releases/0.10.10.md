# Rudonium Anki Toolkit 0.10.10 · Update 1

## Русский

- Рядом с переключателем двустороннего режима добавлена кнопка **Синхронизировать**. После ручного запуска двусторонней синхронизации Obsidian сообщает о результате, в том числе когда изменения отсутствуют или есть записи для проверки. Настройка **Предпросмотр при каждом запуске** управляет автоматическим открытием окна.
- При одностороннем экспорте, если после предыдущей подтверждённой синхронизации обычное текстовое поле изменилось в обоих приложениях, Rudonium переносит новый текст из Obsidian в ту же запись Anki. Если правку сделали только в Anki, поле сохраняет это значение. Когда общей исходной версии нет или операция может удалить данные, откройте предпросмотр экспорта из уведомления и выберите действие.
- В настройках переключатель языка расположен перед разделом «О плагине». В этом разделе можно открыть вопрос или сообщить об ошибке. [GitFlic Issues](https://gitflic.ru/project/dashiwak/rudonium-anki-toolkit/issue)
- Обновление сохраняет номер плагина 0.10.10. После сборки скопируйте три файла из `Rudonium-Builds/0.10.10/install/` в папку плагина Obsidian. Установочный ZIP для распространения создаёт команда `Prepare-Release.cmd`. [Порядок сборки](../../PUBLISHING.md)

Первая сборка 0.10.10 исправила остановку с сообщением `Expected an ordinary file` при переносе готовой сборки в постоянную папку. Update 1 включает это исправление.

## English

- A **Sync now** button is available beside the bidirectional switch. A manual bidirectional sync reports the outcome, including unchanged notes and items that need review. **Preview every sync** controls whether the preview opens automatically.
- During one-way export, if an ordinary text field changed on both sides since its last confirmed sync, Rudonium sends the new Markdown text to the same Anki note. If only Anki changed, the field keeps its Anki value. When there is no common baseline or the operation could remove data, open the export preview from the notice to choose what to do.
- Interface language appears above **About the plugin**. The About section links to support for questions and bug reports. [GitFlic Issues](https://gitflic.ru/project/dashiwak/rudonium-anki-toolkit/issue)
- The plugin version remains 0.10.10. After building, copy the three files in `Rudonium-Builds/0.10.10/install/` into the Obsidian plugin folder. To create a distributable installer ZIP, run `Prepare-Release.cmd`. [Build instructions](../../PUBLISHING.md)

The first build of 0.10.10 fixed an `Expected an ordinary file` error when moving a verified build into its final folder. Update 1 includes that fix.

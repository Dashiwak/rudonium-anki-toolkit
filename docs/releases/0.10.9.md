# Rudonium Anki Toolkit 0.10.9

## Русский

В журнале сборки 0.10.8 для Windows Rollup создал `main.js` за 30,1 секунды. После этого удаление временного каталога `node_modules` в синхронизируемой папке завершилось ошибкой `ENOTEMPTY`. Сборка остановилась до двух контрольных пересборок и создания установочного комплекта.

В 0.10.9 npm работает в отдельной временной папке системы. Сборщик переносит нужные файлы в чистую копию для проверки. Обе контрольные пересборки должны побайтно совпасть с первым результатом. Готовый плагин появляется в `Rudonium-Builds/0.10.9/install/rudonium-anki-toolkit/`.

Обновление накопительное от 0.10.4. Оставьте полный архив базы в `Rudonium-Incoming`, распакуйте пакет 0.10.9 в отдельную папку и запустите из неё `Apply-Update.cmd`. [Порядок сборки](../../PUBLISHING.md)

## English

In a reported Windows build of 0.10.8, Rollup produced `main.js` in 30.1 seconds. Cleanup of the temporary `node_modules` directory in a synced folder then failed with `ENOTEMPTY`. The build stopped before checking the two independent rebuilds and creating the installer.

In 0.10.9, npm runs in a separate system temporary directory. The builder stages a clean copy of the required files for verification. Both independent rebuilds must match the first output byte for byte. The verified plugin is placed in `Rudonium-Builds/0.10.9/install/rudonium-anki-toolkit/`.

The update is cumulative from 0.10.4. Keep the full base archive in `Rudonium-Incoming`, extract the 0.10.9 update to its own folder and run `Apply-Update.cmd` from there. [Build instructions](../../PUBLISHING.md)

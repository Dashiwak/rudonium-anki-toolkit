# Rudonium Anki Toolkit 0.10.2 — Public Beta

## English

The source kit now has one editable copy of the TypeScript modules in `src/`. Run `Open-Source.cmd` to expand the project for editing. `Build-Plugin.cmd` then builds those sources into `Plugin-0.10.2/main.js`. The release workflow keeps the current guides, version history and third-party notices together.

For installation, download `Rudonium-0.10.2.zip` from the release. Close Obsidian and copy the enclosed `rudonium-anki-toolkit/` folder into your vault’s `.obsidian/plugins/`. Keep your existing plugin settings when updating. [Support](https://gitflic.ru/project/dashiwak/rudonium-anki-toolkit/issue)

## Русский

В комплекте для сборки у каждого модуля TypeScript одна редактируемая копия в `src/`. Чтобы открыть проект для редактирования, запустите `Open-Source.cmd`. Команда `Build-Plugin.cmd` соберёт ваши исходники в `Plugin-0.10.2/main.js`. В репозитории сохранены действующие руководства, история выпусков и сведения о сторонних компонентах.

Для установки скачайте из релиза `Rudonium-0.10.2.zip`. Закройте Obsidian и скопируйте папку `rudonium-anki-toolkit/` из архива в `.obsidian/plugins/` своего хранилища. При обновлении сохраните свои настройки. [Поддержка](https://gitflic.ru/project/dashiwak/rudonium-anki-toolkit/issue)

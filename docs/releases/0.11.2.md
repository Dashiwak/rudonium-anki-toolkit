# Rudonium Anki Toolkit 0.11.2

## Русский

- Карточки Obsidian To Anki и страницы Rudonium уже распознаются при обычном экспорте. При переходе отключите прежний плагин, оставьте его папку с настройками и при первом включении Rudonium подтвердите копирование. Мастер переноса файлов предназначен для сторонних форматов, которым нужно преобразование.
- Папка сканирования и шаблоны исключений прежнего плагина учитываются при импорте настроек. Если вы уже перешли на более раннюю версию Rudonium, сверьте область сканирования со своими прежними настройками.
- В мастере переноса папку можно найти по части пути или выбрать в дереве. Стрелки перемещают выделение, Enter подтверждает выбор.
- Под ссылкой на помощь идут подключение к Anki, настройки синхронизации и основные разделы в привычном порядке. Параметры по умолчанию и действия по обслуживанию можно свернуть.
- После ручной двусторонней проверки число записей и результат выводятся отдельными строками.

## English

- Regular export reads Obsidian To Anki cards and Rudonium pages directly. When switching, disable the old plugin, keep its settings folder and confirm the settings copy on Rudonium’s first launch. The card file migration wizard offers external formats that need conversion.
- Settings import carries over the original scan folder and file exclusion patterns. If you previously switched to an earlier Rudonium version, compare its scan scope with your original settings.
- Find a migration folder by typing part of its path or browsing the folder tree. Use the arrow keys to move the selection and Enter to confirm.
- Anki Connection and Sync settings appear immediately below the help link, followed by the main settings in their familiar order. Defaults and maintenance actions now collapse.
- Manual bidirectional sync reports the number of notes checked and the outcome on separate lines.

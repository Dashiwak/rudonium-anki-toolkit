# Rudonium Anki Toolkit 0.11.3

## Русский

**Update 2.** Исправлена ошибка сборки TypeScript при записи статуса приостановки в журнал. Плагин запоминает раскрытые разделы настроек. В «Быстром старте» добавлены шаги установки и настройки AnkiConnect для первой синхронизации.

- Уведомления сообщают, сколько записей добавлено, изменено или удалено. Простая сверка с Anki больше не увеличивает число изменённых записей. Пропуски и ошибки показываются отдельно.
- В настройках синхронизации можно включить журнал изменений для одностороннего экспорта и двустороннего обмена. В нём можно найти запись по файлу или ID и сравнить значения изменённых полей. По умолчанию журнал выключен. После включения он сохраняется в папке плагина этого хранилища.
- Для карточек со знаком `::` плагин распознаёт пропущенный рядом пробел, если формат и границы полей определены однозначно. Например, в связанной карточке `- Казематы:: Сводчатые помещения :: R` он восстановит пробел перед разделителем при применении синхронизации.
- Рядом со ссылкой на помощь появились кнопки для раскрытия и сворачивания всех разделов настроек.

## English

**Update 2.** Fixed a TypeScript build error in suspension history. Rudonium remembers which settings sections are open. Quick Start now explains how to install and configure AnkiConnect for the first sync.

- Sync notices report the number of notes added, edited or deleted. Checking an unchanged note no longer counts as an edit. Skips and errors have separate messages.
- Sync settings now include an optional history for one-way exports and bidirectional sync. Find a note by file or ID and compare field values before and after a change. History is off by default. When enabled, it is stored in the plugin directory for the current vault.
- For cards with a `::` separator, sync can restore missing spaces when the card format and field boundaries are unambiguous. For example, it can fix `- Term:: Definition :: R` when applying changes to a linked card.
- Buttons next to the help link expand or collapse all settings sections.

# Rudonium Anki Toolkit 0.13.1

## English

- After switching from Obsidian_to_Anki, note type rules show your custom expressions and field assignments. Leaving File and Context at the first Anki field no longer adds a rule for every note type.
- Quick Start fits the deck, note type and format selectors within a narrow window. Connection messages use a softer background, and the guide opens in the selected language.
- When a deck audit finds a note that survives only in Anki, preview its Markdown and original ID. Rudonium can locate the source using File or Context and append a verified block after confirmation. Unsupported field markup stays available as a copyable draft with the original fields for comparison.
- Open in Anki requests the note in the Anki browser and reports the result. The English switching guide explains how to verify imported fields and check a linked card before syncing.
- Quick Start keeps your selections when you reconnect to the same profile with the same note fields. Closing settings cancels a pending invitation to Quick Start.
- Custom expressions can use a Web Worker when the desktop renderer restricts Node worker threads.
- Markdown export preserves legacy formatting for numbered examples written with a closing parenthesis, short table separators, typographic ellipses and nonbreaking spaces.

## Русский

- После перехода с Obsidian_to_Anki список правил учитывает ваши регулярные выражения и назначения полей. Выбор первого поля в File и Context больше не добавляет отдельное правило для каждого типа записи.
- В узком окне «Быстрого старта» помещаются списки колод, типов записей и форматов. У сообщений о соединении более мягкий фон. Руководство открывается на выбранном языке.
- Если запись осталась только в Anki, аудит показывает её Markdown и исходный ID. Rudonium находит заметку по File или Context и после подтверждения добавляет проверенный блок. Для неподдерживаемой разметки доступны копируемый черновик и исходные поля для сравнения.
- Кнопка «Открыть в Anki» запрашивает запись в обозревателе Anki и сообщает результат. В английской главе о переходе описано, как сверить перенесённые поля и проверить связанную карточку перед синхронизацией.
- При повторном подключении к тому же профилю с прежним набором полей «Быстрый старт» сохраняет ваш выбор. Закрытие настроек отменяет отложенное открытие мастера.
- Если окно Obsidian ограничивает доступ к потокам Node.js, обработка пользовательских выражений может выполняться через Web Worker.
- В экспорте сохранено прежнее оформление нумерованных примеров со скобкой, коротких разделителей таблиц, многоточий и неразрывных пробелов.

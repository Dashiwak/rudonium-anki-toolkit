# Rudonium Anki Toolkit 0.12.3

## Русский

- В «Быстром старте» результат проверки подключения виден даже при раскрытой инструкции по AnkiConnect. Если подключиться не удалось, окно показывает, что проверить перед следующей попыткой.
- При настройке первой карточки можно выбрать готовый формат RemNote или скопировать его регулярное выражение.
- В двустороннем предпросмотре кнопка «Пропустить» сохраняет выбор для текущего запуска. Можно подтвердить пропуск и применить выбранные направления к остальным полям.
- В английском и русском README появились пример о Байкале, иллюстрации, результаты сравнения повторного экспорта и сведения о поддержке и авторах.

## English

- Quick Start keeps the connection result in view when the AnkiConnect instructions are expanded. If the connection fails, the dialog explains what to check before trying again.
- When setting up a first card, choose the RemNote preset or copy its regular expression.
- In the bidirectional sync preview, Skip records a choice for the current run. You can confirm the skip and apply the selected directions to other fields.
- Both READMEs include a Lake Baikal example, updated illustrations, repeat-export benchmark results, support details, and project credits.

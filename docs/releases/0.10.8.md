# Rudonium Anki Toolkit 0.10.8

## Русский

При обновлении с 0.10.5.1 проверка в 0.10.7 могла остановиться на `PROVENANCE.json` с сообщением `Canonical base normalization failed`. Это происходило во временной папке при подготовке исходников, до компиляции.

Команда `Apply-Update.cmd` теперь собирает исходное дерево из точных байтов проверенной базы 0.10.4 и файлов накопительного пакета. Перед компиляцией она сверяет SHA-256 каждого файла с манифестом версии 0.10.8. Ручная правка `PROVENANCE.json` и настройка окончаний строк Git не требуются.

С версии 0.10.5.1 можно перейти сразу на 0.10.8. Распакуйте новый ZIP в отдельную папку внутри `Rudonium-Incoming`, сохраните там полный архив базы 0.10.4 и запустите `Apply-Update.cmd` из папки обновления. [Порядок сборки](../../PUBLISHING.md)

## English

When updating from 0.10.5.1, the 0.10.7 updater could stop at `PROVENANCE.json` with the message `Canonical base normalization failed`. The failure occurred in the temporary source directory before compilation.

`Apply-Update.cmd` now reconstructs the source tree from the exact bytes of the verified 0.10.4 base and the files in the cumulative update. It compares every file’s SHA-256 with the 0.10.8 source manifest before compiling. You can keep your current Git line-ending settings and leave `PROVENANCE.json` as delivered.

To update directly from 0.10.5.1, keep the full 0.10.4 base archive in `Rudonium-Incoming`, extract the new ZIP into its own folder there and run `Apply-Update.cmd` from that folder. [Build instructions](../../PUBLISHING.md)

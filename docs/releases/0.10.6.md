# Rudonium Anki Toolkit 0.10.6

## Русский

Версия 0.10.6 включает изменения интерфейса и синхронизации рабочей сборки 0.10.5.1. Помощь и основной переключатель двусторонней синхронизации находятся вверху настроек, выбор языка — внизу. При выключенном автоматическом предпросмотре изменения, которые можно применить, передаются в фоне. Конфликты можно открыть вручную.

Для владельца проекта обновление исходников и проверенная сборка теперь выполняются за один запуск `Apply-Update.cmd`. Номер `0.10.6` используется в манифесте, путях сборки и именах архивов. Команда `Prepare-Release.cmd` проверяет выбранную сборку и собирает её материалы для публикации. [Сборка и назначение файлов](../../PUBLISHING.md)

## English

Version 0.10.6 includes the interface and sync changes from working build 0.10.5.1. Help and the main bidirectional sync switch are at the top of settings, with interface language at the bottom. When automatic preview is off, eligible changes sync in the background. Open the preview manually to resolve conflicts.

For maintainers, `Apply-Update.cmd` applies the cumulative source update and builds the plugin in one run. The manifest, build directory and archive names share version `0.10.6`. Run `Prepare-Release.cmd` to verify the selected build and assemble the publication files. [Build instructions and release assets](../../PUBLISHING.md)

# Rudonium Anki Toolkit 0.10.13

## Русский

- При первой двусторонней синхронизации после одностороннего экспорта Rudonium сверяет связанное поле с последним подтверждённым значением для этого профиля Anki и типа записи. Если менялась только одна сторона, правка переносится в нужном направлении. Для остальных сопоставленных текстовых полей с расхождениями по умолчанию сравниваются время файла Markdown и время каждой записи Anki. Это работает и для нескольких связанных карточек в одном файле. При одинаковой секунде или неизвестной дате направление выбирается в предпросмотре.
- В формате Knowledge у однострочной карточки с маркером `:: R` можно изменить вопрос в Anki и сохранить ответ, маркер обратной карточки и ID в Markdown. Например, новая версия вопроса `Казематы===` сохраняет знаки равенства в конце слова.
- Прежние привязки с ID без даты распознаются и за пределами раздела карточек, когда пользовательское правило экспорта подтверждает ту же запись и её границы. Повторное открытие предпросмотра после правки в Anki учитывает актуальное значение поля.
- Свёрнутый раздел **Настройки синхронизации** находится под строкой **Двусторонняя синхронизация** с кнопкой запуска. Элементы страницы настроек выровнены слева.

Для перехода с 0.10.12 распакуйте `Rudonium-0.10.13-Update.zip` в `Rudonium-Incoming` и запустите `Apply-Update.cmd`. После успешной сборки установочные файлы находятся в `Rudonium-Builds/0.10.13/install/`. [Порядок сборки](../../PUBLISHING.md)

## English

- When switching from one-way export to bidirectional sync, Rudonium compares linked fields with their last confirmed values for the Anki profile and note type. An edit on one side is transferred to the other. For other conflicting mapped text fields, the default is to compare the Markdown file time with the time of each Anki note, including several linked notes in one file. Conflicts with equal or unknown timestamps remain available in the preview.
- In a one-line Knowledge card using `:: R`, changing the question in Anki preserves its answer, reverse marker and note ID in Markdown. A question such as `Казематы===` retains its trailing equals signs.
- Legacy undated IDs also work outside a card section when the configured export rule confirms the same note and source range. Reopening the preview after an Anki edit reads the current field value.
- The collapsed **Sync settings** section sits below the **Bidirectional sync** switch and run button. Settings controls are aligned to the left.

To update from 0.10.12, extract `Rudonium-0.10.13-Update.zip` under `Rudonium-Incoming` and run `Apply-Update.cmd`. The local build writes the installation files to `Rudonium-Builds/0.10.13/install/`. [Build instructions](../../PUBLISHING.md)

# Rudonium Anki Toolkit 0.11.0

## Русский

- При первой ручной двусторонней синхронизации плагин дожидается сохранения открытой заметки. После запуска Anki он получает схему полей, в том числе при открытии предпросмотра из настроек.
- При переносе полей в обе стороны сохраняются буквальные окончания `===-`, `====-` и `====.`. Например, изменённый вопрос «Казематы===-» может перейти из Anki в Obsidian вместе с прежней привязкой к записи. Для парных маркеров выделения `==текст==` и неоднозначных изменений в двух открытых редакторах действуют прежние ограничения безопасности.
- Обновлены обращения к API Obsidian, обработка окон и стили интерфейса. WebDriver теперь входит в зависимости разработки.
- При подготовке будущего выпуска GitHub Actions сверяет контрольные суммы трёх установочных файлов перед созданием подтверждений происхождения.

Для установки распакуйте `Rudonium-0.11.0-Update.zip` в отдельную папку в `Rudonium-Incoming`. Запустите `Apply-Update.cmd`. После успешной сборки скопируйте три файла из `Rudonium-Builds/0.11.0/install/` в папку плагина тестового хранилища и включите плагин. [Порядок сборки](../../PUBLISHING.md)

## English

- Manual bidirectional sync waits for the active note to be saved before comparing linked fields. Opening the preview from settings retrieves the field schema after Anki starts.
- Linked fields can carry literal endings such as `===-`, `====-` and `====.` in either direction. Existing review safeguards remain in place for paired highlight markup such as `==text==` and for inconsistent edits in split panes.
- Updated Obsidian API calls, window handling and styles. WebDriver is now a development dependency.
- The tagged release workflow checks the three plugin files against the verified build before generating their GitHub attestations.

To update from 0.10.13, extract `Rudonium-0.11.0-Update.zip` into its own folder under `Rudonium-Incoming` and run `Apply-Update.cmd`. After a successful build, the three plugin files are in `Rudonium-Builds/0.11.0/install/`. [Build instructions](../../PUBLISHING.md)
